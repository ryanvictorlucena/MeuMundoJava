# Operadores aritmeticos

- soma + (também usado como concatenação quando tem uma string junto de um inteiro, por exemplo: soma = 10, print("A soma é " + soma));
- subtração -;
- multiplicação *;
- divisão /;
- resto da divisão %;

## Relacionais

- maior que (x > y);
- menor que (x < y);
- maior ou igual (x >= y);
- menor ou igual (x <= y);
- igual ==;
- diferente !=;

## Lógico

- and && -> ambos devem ser verdadeiros para satisfazer
- or || -> se um for verdadeiro satisfaz

## Atribuição

- soma +=;
- subtração -=;
- multiplicação *=;
- divisão /=;
- incrementar 1 ++;
- decrementa 1 --;
(ao incrementar ou decrementar, se for antes ele primeiro faz a operação e depois retorna, se for depois ele primeiro retorna e depois faz a operação)
